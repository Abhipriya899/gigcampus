# GigCampus

Hyperlocal gig marketplace for students. Urgent one-day jobs (cafes, events,
moving help) matched with verified, rated student workers.

**Domain:** FinTech & Digital Economy
**Live:** https://YOUR-LINK.vercel.app

## Problem
Students need quick pocket money; small businesses need urgent short-term help.
Existing job platforms are built for long-term hiring and lack trust checks.

## Features
- Poster and Student roles
- Post gigs with pay, hours, location
- Apply / accept flow
- Verified badges and two-way ratings
- (add the new features here as you build them)

## Tech stack
React (Vite), Tailwind + DaisyUI, Firebase Auth + Firestore, Vercel
